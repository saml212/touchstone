## D6 — dispatcher / non-free-function tools (flight), fixed generally after coordinator note

flight's tools dispatch through `execute_function(client, name, args)` needing a constructed client,
which `import_path(**arguments)` can't call. Fixed like entry.py fixed entrypoints: the survey
provider generates `agent/invoke.py` with `invoke(name, arguments)` that calls the customer's real
tool as their code does (constructing the client from env, never copying code), adapter-checked
against the live simulator; fidelity, task criteria, and the replica dispatch route through it when
it passes, else fall back to the import path. Re-running the flight survey with invoke.py active is
expected to raise its fidelity from 0%.
