# v3 Stage 5 — train plugin (Harbor jobs → distillation + RL datasets)

Turn finished Harbor job dirs into the files a training stack consumes. Reads job dirs only; stops
at the GPU line. Contract: docs/DESIGN.md "Train".

## Routing (per student task)
- rate == 1        → hold_out
- 0 < rate < 1     → rl
- rate == 0, teacher success exists → distill
- rate == 0, no teacher success     → stuck

## Decisions / simpler-option notes
- Route over tasks present in the STUDENT jobs (student is what we build data for); teacher-only
  tasks are not routed. Noted.
- CLI `--student` stays a single dir (brief); rl band needs >1 trial per task, which single-trial
  jobs never give, so live shows distill + hold_out. datasets fns take lists for the plugin path.
- Teacher success = any teacher trial of the task with reward >= threshold (same test as distill).
- Live teacher = packaged baseline 7/7 (2026-09-25__00-40-31); student = replica 4/7
  (2026-09-25__00-00-10).
- Plugin captures job.job_dir in on_job_start, writes in on_job_end (JobResult has no dir).

## Stage 5b — real RL band (coordinator follow-up)
Added `--attempts N` (default 3) for the `--teacher/--student provider/model` path (passes Harbor's
`-k/--n-attempts` via extra args through touchstone.harbor.run) and made `--teacher/--student`
accept a comma-separated list of job dirs (pooled — pass rates read across all). Default `--out` is
now `<dataset>/train` (= jobs_dir.parent/train).

Live verify (real data, pooled replica jobs — no cost): teacher = packaged 7/7 `00-40-31`,
student = three replica jobs `00-00-10,00-23-46,00-31-13` (3 attempts/task):

    distill: 7 trajectories from 7 tasks · rl: 4 tasks (pass 0.33–0.67) · hold-out: 3 · stuck: 0
    → <dataset>/train/

The central 0<rate<1 routing is now a real fraction (4 rl tasks). The `--student provider/model
--attempts 3` OpenAI spec-run could not be executed live here: no OPENAI_API_KEY on the MacBook or
mini keychain and local Docker is down; the spec+attempts wiring is proven by the CLI unit test
asserting `--n-attempts` reaches harbor. Pooling real replica jobs exercises the identical
rl_tasks/route path on real measurements instead.
