# Touchstone v3 — Stage 4 (the review room over finished tasks/trials, voice or text) plan-as-state

Contract: `docs/DESIGN.md` (Review §) + stage4-brief. Builds on stage-3 `touchstone/harbor/*`,
`touchstone/survey/*`, `touchstone/interview/*` (rooms + speech + realtime), `touchstone/store.py`
(`reviews` table), `touchstone/server/*`.

## Facts learned from the code (verified this session)
- Room text turn: `server/routes/rooms.py` builds an agent per turn, calls `respond(history) ->
  AgentTurn(say, draft, commit)`, and exposes `draft`/`committed` + messages in `_room_state`.
  The WS `test_websocket_sends_state_then_events_in_order` asserts a `draft` event fires. Server
  tests assert only role=assistant/count on the opening, not its text → safe to swap the agent.
- Realtime (`interview/realtime.py`) narrates only (TOOLS=[]) and builds instructions from
  `Interviewer(...).open_statement()`; a test asserts `tools == []` + topic in instructions →
  **reuse realtime + Interviewer as-is** (brief: reuse speech/realtime). Voice review = smoke only.
- Provider tool loop pattern (from `harbor/agent._loop`): `provider.chat(messages, tools)` →
  `Reply(content, tool_calls=[{id,name,arguments(json-str)}])`; append assistant + role="tool"
  messages, loop to a step cap. ScriptedProvider emits tool_calls via Rules (tests).
- Criteria files rewardkit writes: `tests/correctness/{state,trajectory}.py` = `import rewardkit as
  rk` + `rk.FN(args)` lines; `tests/safety/no_pii.py` self-contained; `tests/reward.toml` dimension
  weights; `write_judge` = `[judge]`+`[[criterion]]` toml. task.toml `[metadata.touchstone].job`
  is the job-to-be-done label (shared-criteria grouping for "always").
- `harbor job regrade <job_dir> -p <tasks_dir>` regrades from recorded artifacts (no agent), writes
  a NEW job dir; match by task name. `run.py` syncs the dataset up (excl jobs) + job dir back over
  ssh when no local Docker — regrade mirrors that (sync tasks + the one job up, run, sync back).
- Example live data at ~/Pebble/Github/touchstone-example/touchstone: 7 gated tasks; jobs/ has an
  oracle job (all 1.0) and replica jobs with issue-a-refund at 0.75/0.875 (verifier-unsure material).

## Design decisions (simpler option, noted per brief)
- **New package `touchstone/review/`; keep `interview/agent.py` Interviewer** (realtime + interview
  CLI still use it). The **text** room path uses `ReviewAgent`, which keeps the `AgentTurn` +
  `draft()/committed()` contract and adds `review_state()` (trust, current trial, criteria, filters)
  merged into `_room_state` under `"review"`.
- **Scratch state** (current trial + proposed change) persists as a role="draft" room_message JSON
  (reuses the existing draft filter); **trust** is computed from the `reviews` table.
- **Tool surface (≤6)**: `list_trials(filter)`, `read_trial(task, trial)` (also sets current),
  `record_review(task, trial, verdict, note)`, `propose_change(task, change)`→read-back,
  `apply_change(task, change, always)`→regrade→deltas. 5 tools.
- **Trials** addressed as `<job>/<trial_dir>`; list_trials scans every job dir under jobs_dir and
  orders: verifier-unsure (0<reward<1 or judge) → models-disagree → never-reviewed → needs-review.
- **changes.py** round-trips: `.py` criteria lines (ast parse: `import rewardkit as rk` + `rk.*`
  calls; add/edit/remove by call signature), `reward.toml` dimension weights, judge `.toml`
  descriptions, and `{"op":"text"}` for instruction/persona. Unparseable/hand-edited file → refuse.
- **`always`** = apply to every task under `tasks/` sharing the same `[metadata.touchstone].job`,
  path-adjusted, then ONE regrade.
- **`review` CLI** mirrors `interview` (open room + browser; needs `touchstone serve`); `--dataset`
  / `--jobs-dir` resolve via `[review]` settings (defaults touchstone/ + touchstone/jobs).
- **UI**: new `review.html` + `review.js` served at `/rooms/{id}`; left = trial (instruction,
  trajectory transcript, criteria+scores), right = conversation (PTT/text) + trust + next-trial +
  filter chips. Chips/next send chat messages (no new endpoints). Vanilla JS, existing aesthetic.

## Rules
Same as every stage. Horizontal: `touchstone/review/*` names no product; everything the room says
comes from the dataset files. Never print secrets. Never pause for input; simpler option + note.

Regrade-enablement fixes found live (each committed + unit-tested): tasks now author a **separate
verifier** (`[verifier] environment_mode = "separate"`) with declared **artifacts** (trajectory,
output.json, each simulator state.db) and a **tests/Dockerfile** that bakes the tests into the
verifier image; `[environment] network_mode = "public"` so the verifier can `uvx` harbor-rewardkit;
and `run.py` passes an **absolute `-o`** to remote harbor run/regrade (a relative path made Harbor's
`docker compose cp` resolve artifacts against the task's tests dir and fail). Oracle went from 7×
FileNotFoundError/RewardFileNotFoundError to 7/7 once all four were in place.

Simpler-option notes: realtime stays on the v2 interview agent (voice narration; the tool-driven
review runs over the text path, per brief "reuse speech as-is"); the deterministic agree/disagree
turns were driven through the real `ReviewAgent` (the exact class the server's `_agent_step` builds)
with a scripted provider, while the regrade, dataset, files, and reviews rows are all real.
