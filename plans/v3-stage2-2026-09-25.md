## Facts learned from the code
- Recordings store only `kind='model'` spans (no tool spans). A tool call is in a model span's
  `output.message.tool_calls`; its result is a `role=tool` message in a LATER span's
  `input.messages`, matched by `tool_call_id`. `recordings.tool_events` reconstructs
  (tool, arguments, output) triples from this.
- Example tools: order_status→GET /orders/{id}, refund→POST /orders/{id}/refund, escalate→POST
  /tickets, send_email→POST /emails. Service base_url_env=ORDERS_URL default http://127.0.0.1:8710.
- agent.py builds `httpx.Client(base_url=ORDERS_URL)` at IMPORT time → replay must set the env var
  before importing the tool module.
- Example's installed touchstone (.venv site-packages) is non-editable and lacks survey; live
  verify needs a transient `uv pip install` of local touchstone into that venv (untracked, no
  tracked-file change). Tests avoid this via `[survey] python` = current interpreter.
- Repo-wide complexipy already has pre-existing violations; gate NEW survey code to ≤8 only.
