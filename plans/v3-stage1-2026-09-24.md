## Harbor facts (verified against harbor 0.21 local / docs)
- `harbor run -p <task-or-dataset-path> -a <agent|module:Class> -m <provider/model> -o <jobs-dir> -n <n_concurrent> -e docker -y`
- Custom agent = import path passed to `-a` as `module.path:ClassName`. kwargs via `--ak k=v`, env via `--ae K=V`.
- Job dir: `config.json`, `result.json` (job-level: `stats.evals`), per-trial dir `<task>__<rand>/`.
- Trial dir: `result.json` (`task_name`, `agent_info`, `exception_info`, `agent_result`…), `config.json`, `verifier/reward.{txt,json}`, `agent/`, `artifacts/`, `exception.txt`.
- Reward file: `verifier/reward.txt` (float) or `verifier/reward.json` (`{"reward":..}` or multi-dim `{"correctness":..,..}`).
- Trajectory (rewardkit trajectory criteria default): `/logs/agent/trajectory.json` (ATIF).
- dataset.toml: `[dataset]` name/version/description/authors/keywords + top-level `tasks = []`.
- rewardkit: `uvx --from 'harbor-rewardkit==0.2.*' rewardkit /tests`; `@criterion def f(workspace: Path)->bool|float`; builtins `sqlite_query_equals`, `trajectory_tool_used/not_used`, `json_key_equals`…; judge TOML `[judge]`+`[[criterion]]`.
